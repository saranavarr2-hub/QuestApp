Descripción
Una aplicación nativa para Android diseñada para la gestión integral de partidas de rol. Permite administrar personajes, inventarios, reglas en tiempo real y lanzamiento de dados, todo sincronizado en la nube.

Características:
Gestión de Acceso: Autenticación segura mediante Firebase.

Sincronización en Tiempo Real: Base de datos Firestore para actualización instantánea de reglas e inventario.

Gestión de Personajes: Biblioteca con visualización de fichas en formato PDF.

Herramientas de Juego: Sistema modular de lanzamiento de dados aleatorios.
Posibilidad de gestionar reglas rápidas y otras opciones.
